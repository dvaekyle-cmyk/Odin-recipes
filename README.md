# Odin Recipes

My Filipino recipe website for **ITE 10 – Introduction to Computing, Practical Exercise 5: HTML Development** at Caraga State University.

**Live site:** https://dvaekyle-cmyk.github.io/Odin-recipes/

## About the Project

Odin Recipes (Gather & Graze) is a multi-page website featuring three Filipino dishes: **Chicken Adobo**, **Sinigang na Baboy** and **Leche Flan**. It applies the fundamentals of HTML: semantic page structure, navigation links, images, lists, tables, a video and a feedback form.

## Pages

| Page | File |
|------|------|
| Homepage | `index.html` |
| Chicken Adobo | `chicken-adobo.html` |
| Sinigang na Baboy | `sinigang.html` |
| Leche Flan | `leche-flan.html` |
| Feedback form | `feedback.html` |

## Features

- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Recipe information tables with captions and header cells
- Ingredient lists (`ul`) and instruction lists (`ol`)
- Captioned video with a text track (`chicken-adobo.mp4`, `chicken-adobo.vtt`)
- Feedback form with labels, a drop-down, radio buttons and a text area
- Accessibility: skip link, image alt text, keyboard focus styles, descriptive headings
